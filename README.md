# persona3 — Nomad-Guy Portfolio

A React + Vite portfolio website with a Persona 3 aesthetic.

## Live

https://nomad-guy.vercel.app/

## Repo

https://github.com/nomad-guy/Portfolio

## Pages

- `/` — Menu
- `/about` — About Me
- `/resume` — Resume (Flutter / ML / AI Agents / Backend)
- `/socials` — Socials (GitHub, Telegram, Discord)
- `/projects` — Projects (Noctra, Portfolio)

GitHub opens directly via the menu's GITHUB LINK item.

## Run

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Tech

- React 19
- React Router v7
- Framer Motion
- Vite
